# school_distance_calculator

학생 명단(이름, 주소)을 업로드하면 학교까지의 통학 소요시간을 일괄 계산해 엑셀/CSV로 내려받는 Streamlit 앱입니다.

**카카오 API 기반**입니다. 구글 지도 API에서 옮겨온 이유는 결제 계정(카드) 등록 없이 무료 쿼터만으로 쓸 수 있고, 국내 주소 인식률이 높기 때문입니다.

## 동작 방식

1. **주소 → 좌표** — 카카오 로컬 API `주소 검색`. 도로명/지번으로 못 찾으면 `키워드 장소 검색`으로 한 번 더 시도합니다(아파트명·건물명 대응).
2. **좌표 → 소요시간** — 카카오모빌리티 길찾기 API. 두 가지 모드를 지원합니다.

| 모드 | 사용 API | 호출 수 | 특징 |
|------|----------|---------|------|
| 출발시각 지정 | 미래 운행 정보 길찾기 | 학생 1명당 1회 | 등교 시각(예: 07:00) 기준 예측 교통량 반영 |
| 현재 교통 기준 | 다중 출발지 길찾기 | 30명당 1회 | 호출 수가 적고 빠름, 실행 시점 교통 기준 |

> ⚠️ 카카오는 대중교통 경로 API를 제공하지 않습니다. 소요시간은 **자동차 기준**입니다.

## 설치

```bash
pip install -r requirements.txt
```

## API 키 발급

1. [카카오 개발자센터](https://developers.kakao.com)에서 애플리케이션 추가
2. **앱 키 > REST API 키** 복사
3. 카카오 개발자센터에서 **카카오맵(로컬)** 활성화
4. [카카오모빌리티 디벨로퍼스](https://developers.kakaomobility.com)에서 같은 앱으로 **길찾기 API** 사용 신청

두 서비스 모두 같은 REST API 키를 씁니다. 결제수단 등록은 필요 없습니다.

## 키 설정

`.streamlit/secrets.toml` 파일을 만들고 아래 내용을 넣습니다.

```toml
KAKAO_REST_API_KEY = "여기에_REST_API_키"
```

Streamlit Community Cloud에 배포한 경우에는 앱 설정의 **Secrets** 화면에 같은 내용을 붙여넣습니다.

이 파일은 `.gitignore`에 포함되어 있어 커밋되지 않습니다.

## 실행

```bash
streamlit run commute_app.py
```

## 입력 파일 형식

`이름`, `주소` 두 컬럼이 있는 `.xlsx` 또는 `.csv` 파일입니다. 앱 안에서 템플릿을 내려받을 수 있습니다.

| 이름 | 주소 |
|------|------|
| 김철수 | 서울시 강남구 역삼동 |
| 이영희 | 경기도 성남시 분당구 |

## 결과

이름 · 주소 · 인식된 주소 · 거리 · 소요시간이 표로 나오고 평균/최소/최대 통계가 함께 표시됩니다. 좌표 변환이나 경로 탐색에 실패한 학생도 **행이 사라지지 않고** 오류 사유와 함께 남습니다.

## 설정 바꾸기

목적지 학교 주소는 `commute_app.py` 상단의 `SCHOOL_ADDRESS` 상수입니다.

```python
SCHOOL_ADDRESS = "경기도 포천시 해룡로 120"
```

## 무료 쿼터

- 카카오 로컬 API: 일 100,000건
- 카카오모빌리티 길찾기 API: 일 10,000건

학생 200명 기준으로 좌표 변환 200건 + 경로 탐색 200건(출발시각 지정) 또는 7건(현재 교통 기준)이므로 무료 범위 안에서 충분합니다.
